This repo is to figure out the simulation differences between genesis and mujoco.

First, run:
```
python3 test/record_g1_xhand.py
```

This saves actions and states of the 53dof robot into a .npz file.

Then, run:
```
python3 test/unitree_mujoco_reproduce.py
```

This plots the states from genesis as red and white debug balls, and sets recorded actions from genesis as ctrl commands in mujoco.


The following joint properties are copied across the two simulators: 
1. kp
2. kd
3. armature
4. stiffness
5. damping
6. frictionloss

We also set other physical parameters the same:
1. simulation_dt
2. substeps (manually implemented in mujoco)

The .xml file is generated by converting the .urdf file using mujoco's GUI.
